# 가게 제외 규칙 — 어디서 무엇을 거르나 (2026-09-10)

빵집이 아닌 곳, 오늘 걸어 들어가 살 수 없는 곳을 서비스에서 빼는 규칙을 한곳에 모은다.
**규칙이 세 곳에 흩어져 있어서** 한 곳만 고치면 다른 경로로 다시 들어온다.

## 세 자리

| 자리 | 파일 | 무엇을 막나 | 대상 |
|---|---|---|---|
| ① 신규 유입 | `scripts/localdata_new_confirmed.py` | LOCALDATA 인허가에서 새로 들어오는 가게 | 앞으로 생길 것 |
| ② 후보 풀 | `scripts/store_profile_batch.py` `bakery_score` | 추천 후보에서 내림 (삭제 아님) | 이미 있는 것 |
| ③ 서비스 제외 | `store.status = 'DELETED'` (승인 경로) | 검색·지도·빵알람에서도 뺌 | 이미 있는 것 |

**②는 점수라서 되돌리기 쉽고, ③은 데이터라 승인 경로가 필요하다.**

## 규칙 목록

### 프랜차이즈 — ①에만 있음
`FRANCHISE_BRANDS` + 실증 추가(닥터로빈·런던베이글뮤지엄·팀홀튼·디저트39·코코호도).
기존 지점 매칭·폐업 감지는 유지한다(정책 결정, 2026-08).

### 떡·한과·공방 — ②에 있음 · **①에 없음** ⚠️
답례떡·이바지·주문제작 공방은 맛집이 아니라 제작소다.
`NON_BAKERY_HINTS` 에 `떡`·`한과`·`공방` 추가(2026-09-10). 계열 2,464곳 중 후보 통과 270 → 0곳.

- 카테고리 전수 확인: `떡` 이 걸리는 것은 `떡,한과` 1,583 · `떡류제조` 277 · `떡볶이` 15 · `전,빈대떡` 4.
  `BAKERY_CATEGORIES` 와 겹치지 않는다. `떡카페`·`호떡` 은 이미 `카페`·`호떡` 으로 걸리고 있었다.

**할 일:** ① 에도 같은 카테고리 제외를 넣어야 한다. 안 넣으면 다음 LOCALDATA 최신화에 다시 들어온다.

### 100% 예약제 — **제외하지 않는다** (2026-09-10 팀 결정)
한때 774곳을 지우려 했으나 접었다. 예약제 케이크집도 사용자가 찾을 수 있어야 한다.
`visit_mode` 컬럼 안도 함께 폐기했다. 명단은 `matching/reservation_only_delete_candidates_20260910.tsv` 에
남기되 **실행하지 않는다**.

### 공방 · 클래스 · 답례품 전문 — ③ 대상 241곳 (2026-09-10 결정)
"맛집이 아니라 제작소"인 곳을 서비스에서 뺀다. **두 조건을 모두 만족하는 곳만** 지운다.

```
조건 1 (주업 선언)  카테고리 공방·교육 계열
                  또는 소개글에 '답례품 전문' · '클래스 전문' 같은 전문점 표현
조건 2 (팔 물건)    운영 빵 종류 메뉴가 0개
```

**두 조건을 모두 걸어야 하는 이유.** 키워드만으로는 정상 빵집이 대거 걸린다.

| 규칙 | 대상 | 문제 |
|---|---:|---|
| 넓은 키워드(답례품·클래스 언급) | 3,448곳 | "선물하기 좋다" 자랑까지 걸린다. 빵 메뉴 있는 곳이 2,605곳 |
| 전문점 표현만 | 592곳 | 영주네구움과자점(빵 18) · 칼리프(베이킹 스튜디오 출신 베이커리)이 걸린다 |
| **전문점 표현 ∩ 빵 메뉴 0** | **241곳** | 채택 |

빵 메뉴가 18개인데 "답례품 단체주문 전문"이라고 쓴 곳은 빵집이다. 빵을 파는지가 가장 확실한 판별이다.

대상 241곳: 유입 KAKAO_IMPORTED 224 · ADMIN_REGISTERED 17.
카테고리 공방 114 · 떡,한과 45 · 제과,제빵 19 · 카페,디저트 12.
명단: `matching/workshop_class_gift_delete_20260910.tsv`

**할 일:**
- ③ 승인 경로로 241곳 `status = 'DELETED'` (근거 문장을 제안에 첨부)
- ① 에 같은 두 조건을 넣어 재유입 차단

## 최신화 때 다시 확인할 것

최신화(재크롤·재파싱) 뒤에는 아래를 다시 센다. 늘어났으면 ① 의 규칙이 새고 있다는 뜻이다.

```
떡·한과·공방 계열 중 bakery_score >= 0.5 인 곳      (2026-09-10 기준 0곳)
공방·클래스·답례품 전문 ∩ 빵 메뉴 0 중 status='ACTIVE' 인 곳   (지운 뒤 0곳이어야 한다)
```
