# 참조 데이터

지역 resolver(`scripts/region_resolver.py`)가 법정동을 검증하는 기준표다. 코드는 파일의 sha256 을 고정해 두고,
해시가 다르면 판정하지 않고 멈춘다 — 바뀐 기준표로 조용히 판정하면 근거에 남는 버전이 거짓이 된다.

## 정본: `bjd_code_api_20260926.csv` — 행정안전부 법정동코드 API 스냅샷

| 항목 | 값 |
| --- | --- |
| 출처 | 공공데이터포털 [행정안전부_행정표준코드_법정동코드](https://www.data.go.kr/data/15077871/openapi.do) `getStanReginCdList` |
| 받은 날 | 2026-09-26 (`scripts/bjd_reference_snapshot.py`) |
| 인코딩 | UTF-8, 코드순 정렬(같은 내용이면 같은 해시) |
| 크기 | 2,520,069 bytes |
| sha256 | `4333ed7bdb62ed7132e02650936877b848b7fd3168bbb00264534d0694130cb5` |
| 행 | 20,560 (현존 코드만) |
| 주요 컬럼 | region_cd · locatadd_nm(전체 이름) · locallow_nm(최하위 이름) · locathigh_cd(상위 코드) · adpt_de(생성일) |

**왜 API 스냅샷인가:** 처음 받은 파일(아래)은 수정일이 08-13인데 내용은 2026-07-01 행정구역 개편 전이었다.
전남광주통합특별시(12)·인천 서해구 등이 없어, 이미 받아 둔 카카오 응답 52,288건 중 4,495건(8.6%)이 풀리지 않았다.
API 스냅샷으로는 52,288건이 모두 해소되고, 해소값은 이미 승인된 지역값과 한 건도 다르지 않다.

**특성:** 시+구 도시(성남시 분당구 등)는 상위 코드가 시를 건너뛰어 도로 간다 — 이름은 전체 이름의 접두로 푼다.
세종은 `3611000000`이 최상위다(`3600000000` 행 없음). 상위 코드가 빈 API 행이 2개 있어(영덕 대동리·통영 당포리)
그때는 코드 자리로 상위 계층을 찾는다.

**해소할 때마다 API를 부르지 않는다:** 판정이 어느 기준표에서 나왔는지 남기려면 고정 파일이 필요하고,
개발계정 일일 한도(10,000회)도 있다. 전체는 1,000건씩 약 21회로 받는다.

정본으로 쓰지 않는다 — 개편 전 내용이다.

## 갱신 절차

1. `python scripts/bjd_reference_snapshot.py` — 오늘 날짜 파일이 새로 생긴다(기존 파일은 덮지 않는다).
2. `scripts/bjd_reference.py`의 `REFERENCE_FILE`·`REFERENCE_VERSION`·`REFERENCE_SHA256`을 함께 올린다.
3. `python scripts/region_resolver.py rejudge --purpose …` — 저장된 원 응답을 새 기준표로 다시 판정해 새 행을 덧붙인다.
   기존 `region_resolution` 행은 그 행이 만들어질 때의 기준표 버전을 그대로 가진다.
