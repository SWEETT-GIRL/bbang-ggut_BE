# Verification Before Completion

완료를 선언하기 전에 반드시 검증 명령을 실행하고, 전체 출력을 확인한 후에만 주장한다.

## 핵심 원칙

**"검증 없이는 완료 선언 없다"** — 이는 절대적이다. 검증 단계를 건너뛰는 것은 비효율이 아니라 부정직한 행위다.

## 5단계 게이트

완료를 주장하기 전에:

1. 어떤 명령이 해당 주장을 증명하는지 파악
2. 해당 명령을 완전하고 새롭게 실행
3. 전체 출력을 읽고 종료 코드 확인
4. 출력이 주장과 일치하는지 확인
5. 그 후에만 증거와 함께 결과 발표

## Spring Boot 검증 명령

```bash
# 전체 테스트
./gradlew test

# 빌드 검증
./gradlew build

# 컴파일만
./gradlew compileJava
```

## 중단하고 검증해야 하는 신호

- "~해야 할 것 같다", "아마도", "보이는 것 같다" 같은 언어 사용 시
- 테스트 실행 전 "완료!", "완벽해!" 표현 시
- 신선한 검증 없이 커밋/PR 계획 시
- 에이전트 보고를 최종 증거로 수용 시
- 전체 검증 대신 부분 확인 시

## 핵심

피로감, 자신감, 이전 부분 확인은 실제 증거를 대체할 수 없다.
