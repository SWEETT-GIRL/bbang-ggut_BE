# Executing Plans

작성된 구현 계획을 체계적으로 실행한다.

## 3단계 워크플로우

### 1. 계획 로드 및 검토

- `docs/superpowers/plans/` 에서 계획 파일 읽기
- 비판적으로 검토
- 우려사항이 있으면 시작 전에 논의

### 2. 작업 실행

각 태스크마다:
- 태스크를 **진행 중**으로 표시
- 계획의 단계별 지침을 **정확히** 따르기
- 각 단계 후 검증 실행
- 완료 시 **완료**로 표시

```bash
# 각 태스크 완료 후 검증
./gradlew test
```

### 3. 개발 완료

모든 태스크 완료 후 → `finishing-a-development-branch` 스킬 사용

## 중단해야 하는 상황 (블로커)

즉시 실행을 멈추고 명확화 요청:
- 누락된 의존성
- 테스트 실패
- 지침이 불명확한 경우

**절대 추측으로 진행하지 않는다.**

## 핵심 원칙

- 계획을 **정확히** 따르기
- 검증을 **절대 건너뛰지** 않기
- 막히면 **도움 요청**하기
