# Apple Guideline 1.2 UGC 대응 Phase TODO

작성일: 2026-06-05

참고: Apple App Store Review Guidelines 1.2
https://developer.apple.com/app-store/review/guidelines/

## 전체 목표

- UGC 앱 요구사항인 게시 전 부적절 콘텐츠 필터링을 리뷰 생성/수정에 적용한다.
- 사용자가 직접 악성 작성자를 차단할 수 있게 한다.
- 차단한 사용자의 리뷰/프로필이 내 화면에서 숨겨지도록 처리한다.
- 신고, 운영 검토, 이용 제한, 이의제기, 고객지원/커뮤니티 가이드라인 URL을 심사 메모에 명시한다.

## 추천 API

| 기능 | API | 비고 |
| --- | --- | --- |
| 작성자 차단 | `POST /blocks` | body: `{ "blockedMemberId": 123 }` |
| 차단 해제 | `DELETE /blocks/{memberId}` | 없는 차단은 `200 OK`로 idempotent 처리 권장 |
| 차단 목록 | `GET /blocks?page=0&size=20` | `{ memberId, nickname, blockedAt }` 반환 |

## Phase 2. 차단 사용자 리뷰 숨김

### 목표

내가 차단한 작성자의 리뷰가 내 화면에서 보이지 않게 한다.

### 범위

- 리뷰 요약 preview 숨김
- 리뷰 목록 숨김
- 리뷰 상세 숨김
- 평균 평점/리뷰 수 계산 기준 반영
- 비로그인 사용자는 기존 동작 유지

### 체크리스트

- [x] `ReviewRepository` active 조회 조건에 "내가 차단한 작성자 제외" 추가
- [x] 리뷰 요약 조회에 차단 필터 적용
- [x] 리뷰 목록 조회에 차단 필터 적용
- [x] 리뷰 상세 조회에 차단 필터 적용
- [x] 차단한 사용자의 리뷰 상세 요청 시 `REVIEW_NOT_FOUND`로 응답
- [x] 평균 평점 계산에서 차단 작성자 리뷰 제외
- [x] 리뷰 수 계산에서 차단 작성자 리뷰 제외
- [x] 목록 content, 평균 평점, 리뷰 수가 같은 필터 기준을 사용하도록 정리
- [x] 비로그인 조회는 기존 동작 유지
- [x] 내가 쓴 리뷰 목록에는 차단 필터 적용하지 않음

### 완료 기준

- [x] 차단한 작성자의 리뷰가 목록에 보이지 않는다.
- [x] 차단한 작성자의 리뷰가 요약 preview에 보이지 않는다.
- [x] 차단한 작성자의 리뷰 상세는 조회되지 않는다.
- [x] 평균 평점/리뷰 수에서 차단 작성자 리뷰가 제외된다.
- [x] 비로그인 사용자의 리뷰 조회 결과는 기존과 동일하다.
- [x] 내가 쓴 리뷰 목록은 차단 상태와 무관하게 유지된다.
