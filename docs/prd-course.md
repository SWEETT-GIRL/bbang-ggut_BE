# PRD: 빵지순례 코스 기능

**작성일:** 2026-06-17  
**최종 수정:** 2026-06-17  
**상태:** 초안

---

## 1. 개요

사용자가 여러 빵집을 묶어 하나의 방문 경로(코스)로 계획할 수 있는 기능.  
운영팀이 제공하는 **큐레이션 코스**를 저장하거나, 직접 빵집을 골라 **커스텀 코스**를 만들 수 있다.

---

## 2. 목표

- 빵집 탐색을 "단일 빵집 방문"에서 "코스 여행"으로 확장
- 큐레이션 코스로 신규 사용자의 탐색 허들 낮추기
- 커스텀 코스로 재방문·활성 사용자의 앱 체류 동기 강화

---

## 3. 앱 네비게이션 구조

```
바텀 네비게이션: 홈 | 코스 | 찜한가게 | 마이
```

| 탭 | 내용 |
|----|------|
| 홈 | 기존 홈 피드 |
| 코스 | 코스 탐색 + 저장한 코스 (서브탭 2개) |
| 찜한가게 | 관심 빵집 위시리스트 |
| 마이 | 마이페이지 |

---

## 4. 기능 범위

### 4-1. 코스 탐색 노출 대상

코스 탐색 서브탭에는 다음 두 종류의 코스가 모두 표시된다.

| 종류 | 조건 |
|------|------|
| 큐레이션 코스 | 운영팀이 등록한 코스 (항상 공개) |
| 커스텀 코스 | 사용자가 공개(`isPublic = true`)로 설정한 코스 |

**코스 카드 표시 정보**

| 항목 | 출처 |
|------|------|
| 대표 이미지 | `CourseImageFile` |
| 코스 제목 | `Course.title` |
| 생성자 닉네임 | `Course.createdBy → Member.nickname` |
| 가게 수 | `CourseStop` 개수 |
| 각 가게의 지역 | `CourseStop → Store.region2` (구 단위, 중복 제거) |

예시 카드:
```
[대표이미지]
소금빵 순례
by 빵순이  |  가게 5개
마포구 · 성동구 · 용산구
```

### 4-2. 큐레이션 코스

| 항목 | 내용 |
|------|------|
| 제공 주체 | 운영팀 (관리자 등록) |
| 구성 요소 | 코스 제목, 설명, 대표 이미지, 빵집 목록(순서 있음), 예상 소요시간 |
| 사용자 액션 | 코스 상세 보기 → **저장** → 저장한 코스 탭에 추가 |
| 노출 위치 | 코스 탭 > 코스 탐색 서브탭 |

### 4-2. 찜한가게 (관심 빵집 위시리스트)

커스텀 코스 생성의 재료가 되는 빵집 보관함. 빵알람(구독)과는 별개의 개념이다.

| 항목 | 내용 |
|------|------|
| 역할 | 나중에 방문하고 싶은 빵집을 모아두는 위시리스트 |
| 추가 방법 | 빵집 상세페이지 "찜하기" 버튼 |
| 노출 위치 | 바텀 네비게이션 > 찜한가게 탭 |
| 활용 | 찜한가게 탭에서 코스 생성 시 빵집 선택 재료로 활용 |

**빵알람 vs 찜한가게 비교**

| | 빵알람 | 찜한가게 |
|---|--------|----------|
| 의도 | 근처 지나갈 때 알림 받기 (수동적·지속적) | 코스 계획을 위해 모아두기 (능동적) |
| 진입점 | 빵집 상세 Primary CTA | 빵집 상세 Secondary CTA |

### 4-4. 커스텀 코스

| 항목 | 내용 |
|------|------|
| 제공 주체 | 사용자 |
| 구성 요소 | 코스 이름, 대표 이미지(선택), 빵집 목록(순서 조정 가능), 가게별 메모(선택), 공개 여부 |
| 생성 플로우 | **2단계** — ① 가게 구성 → ② 코스 정보 입력(제목·이미지·공개여부) |
| 빵집 추가 경로 | ① 코스 생성 화면 내 찜한가게 탭에서 선택 <br> ② 코스 생성 화면 내 지역·메뉴별 랭킹 탭에서 검색/탐색 |
| 편집 | 코스 상세 더보기(…) → 편집 |

---

## 5. 커스텀 코스 빵집 탐색 방식

코스 생성 화면의 "가게 추가" 영역에서 두 탭으로 탐색한다.

```
[찜한가게 탭]
  → 내가 찜한 빵집 목록에서 선택

[지역·메뉴별 랭킹 탭]
  → 검색창 + 지역 / 메뉴(카테고리) 필터
  → 해당 조건의 빵집을 랭킹 점수 순으로 표시
  → 가게별 정렬 옵션 제공
```

| 방식 | 채택 여부 | 이유 |
|------|-----------|------|
| 찜한가게 탭 | ✅ 채택 | 이미 관심 표시한 빵집을 빠르게 코스에 추가 |
| 지역·메뉴별 랭킹 탭 | ✅ 채택 | 새로운 빵집 탐색 + 검색 지원 |
| 반경 선택 UI | ❌ 제외 | 지도 마커로 대체, UI 단순화 |
| 입맛 추천 | 추후 검토 | 추천 시스템 미구현 |

## 6. UX 플로우 전체

### 코스 탭 화면 구조
```
코스 탭
  ├── [코스 탐색] 서브탭 — 큐레이션 코스 목록
  └── [저장한 코스] 서브탭 — 내가 저장/생성한 코스 목록
        우하단 [코스 생성] FAB
```

---

### 코스 상세 (탐색에서 진입)
```
코스 탐색 서브탭 → 코스 카드 탭
  → 코스 상세
      - 지도 경로 미리보기
      - 빵집 리스트 + 빵집 간 거리
      - [좋아요] 버튼
      - [나만의 코스로 편집하기] 버튼
```

**[좋아요]**
- 코스에 대한 좋아요. 누구나 가능 (CURATED·공개 CUSTOM 모두)
- 취소 가능 (토글)

**[나만의 코스로 편집하기]**
- 해당 코스의 빵집 목록을 그대로 복사해 코스 생성 1단계로 진입 (pre-populated)
- 사용자가 가게 추가/삭제/순서 변경 후 제목·이미지·공개여부 입력 → 새 CUSTOM 코스로 저장
- 원본 코스와는 독립된 별도 코스로 생성됨

```
코스 상세 → [나만의 코스로 편집하기]
  → 코스 생성 1단계 (원본 빵집 목록 pre-populated)
    → 가게 추가/삭제/순서 조정·메모 입력
    → [다음] → 코스 정보 입력 (제목·이미지·공개여부)
    → [저장] → 저장한 코스 서브탭에 추가
```

---

### 커스텀 코스 생성 — 진입점 A: 코스 탭 FAB
```
저장한 코스 서브탭 → [코스 생성] FAB

  [1단계] 가게 구성
    → [가게 추가]
        ├── 찜한가게 탭: 찜한 빵집 목록에서 선택
        └── 지역·메뉴별 랭킹 탭: 검색/필터 후 선택
    → 선택한 빵집 순서 드래그 조정
    → 가게별 메모 입력 (선택) — 예: "여기서 소금빵이랑 크루아상 먹기"
    → [다음]

  [2단계] 코스 정보 입력
    → 코스 제목 입력
    → 대표 이미지 첨부 (선택)
    → 공개 여부 선택 (공개 / 비공개)
    → [저장]
```

### 커스텀 코스 생성 — 진입점 B: 빵집 상세에서
```
빵집 상세 → [찜하기]
  → 찜한가게 탭에 저장 (토스트 알림)
  (이후 코스 생성 시 찜한가게 탭에서 선택)
```

---

### 코스 상세 편집
```
코스 상세 화면 → [...] 더보기 버튼
  ├── [편집] → 코스 생성 화면 (기존 데이터 pre-populated)
  └── [삭제] → 확인 후 삭제
```

---

### 코스 상세 내 가게 추가 (편집 모드)
```
코스 상세 화면 → [...] → [편집]
  → [가게 추가] 버튼
    → 하단 영역이 탐색 리스트로 인라인 전환
        ├── 찜한가게 탭
        └── 지역·메뉴별 랭킹 탭 (검색 + 가게별 정렬)
    → 빵집 선택 → 코스 리스트 뷰로 복귀
```

---

## 7. 빵집 상세페이지 버튼 배치

```
[ 빵알람 받기 ]   ← Primary CTA (기존, 큰 버튼)
[ 찜하기 ]        ← Secondary CTA (작은 버튼 or 아이콘)
```

## 8. 데이터 모델 (BE 스케치)

```
Course
  - id
  - type: CURATED | CUSTOM
  - title
  - description (nullable)
  - createdBy: memberId (CUSTOM일 때)
  - estimatedMinutes (nullable, CURATED용)
  - isPublic: boolean
  - deletedAt (soft delete)

CourseStop
  - courseId
  - storeId
  - visitOrder (방문 순서)
  - memo (nullable, CUSTOM만)
  - deletedAt (soft delete)

CourseImageFile (코스 대표 이미지, ImageFile 상속)
  - courseId
  - displayOrder
  - awsKey / mimeType / name

SavedCourse (내 코스 보관함 — CUSTOM + CURATED 통합)
  - memberId
  - courseId

CourseLike (코스 좋아요)
  - memberId
  - courseId
  UNIQUE (memberId, courseId)

WishedStore (찜한가게)
  - memberId
  - storeId
```
