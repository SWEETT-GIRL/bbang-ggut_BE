너는 한국 베이커리 메뉴를 분류한다.

아래 메뉴명 각각에 대해 세 가지를 판단해라.

1. kind — 주어진 분류 목록 중 가장 구체적으로 들어맞는 것 하나.
   '빵'과 '기타'는 정말로 다른 어떤 것에도 해당하지 않을 때만 쓴다.
   예) '소금버터빵' → 소금빵 (빵 아님), '뺑오쇼콜라' → 페이스트리, '튀소구마' → 소금빵,
       '사각 카스테라(초코)' → 카스테라, '팥붕이 10마리' → 붕어빵, '백앙금빵' → 단팥빵
   목록에 딱 떨어지는 값이 없어도 가장 가까운 것을 고른다. 낯선 이름이라고 '빵'으로 도망가지 마라.
   예) '파네토네' → 브리오슈, '팡도르' → 브리오슈, '구겔호프' → 파운드,
       '빨미까레' → 페이스트리, '쇼숑오뽐므' → 페이스트리, '오리지널핫도그' → 소세지빵,
       '햄치즈파니니' → 샌드위치, '양갱' → 화과자, '개성주악' → 화과자,
       '블루베리크럼블' → 파이, '키쉬' → 파이, '에그플랑' → 에그타르트,
       '밀크크레이프' → 크레페, '밤만쥬' → 만쥬, '퐁당쇼콜라' → 케이크,
       '호두쉬폰' → 케이크, '말차테린느' → 케이크, '로투스' → 비스킷,
       '갈레트브루통' → 쿠키, '과일모찌' → 떡, '돼지바' → 아이스크림, '복숭아파르페' → 아이스크림,
       '호두정과' → 한과, '곶감단지' → 한과 (정과·강정·전병·유과 등 한국 전통 과자는 한과),
       '생초콜릿' → 초콜릿, '파베초콜릿' → 초콜릿, '두바이초콜렛' → 초콜릿,
       '두바이쫀득볼' → 쫀득쿠키
   이름이 '빵'으로 끝나면 빵이다 — 떡·과자류로 보내지 않는다.
   예) '옥수수찰떡빵' → 떡 아님, '깨찰빵' → 떡 아님, '호두찰빵' → 떡 아님
   목록의 값은 그 이름의 제품을 가리킨다. 식감이나 재료가 비슷하다고 끌어다 쓰지 않는다.
   예) '깨찰빵'은 쫀득하지만 '쫀득빵'이 아니다

2. isBakeryItem — 빵집·카페에서 파는 '빵/디저트류'면 true.
   음료(커피·차·주스·스무디), 식사류(파스타·리조또·샐러드·피자·튀김·또띠아·버거),
   굿즈·선물세트·포장용기·안내문구는 false. false 여도 kind 는 가장 가까운 값을 고른다.
   빵에 발라 먹거나 곁들이는 스프레드·잼·소스·토핑도 그 자체는 빵이 아니므로 false.
   여러 품목을 묶은 세트·구성품이나 메뉴판의 분류 이름(품목이 아닌 것)도 false.
   예) '허니레몬차' → false, '알리오 올리오' → false, '미미선물세트' → false, '*전화주문안내*' → false,
       '블루베리크림치즈' → false, '플레인크림치즈' → false, '생크림딸기잼' → false, '카야버터' → false,
       '카이막' → false, '브레드바스켓' → false, '옛날과자6종' → false, '오늘의디저트' → false,
       '베이커리류' → false

3. confidence — 0.0~1.0. 메뉴명만으로 확신이 서지 않으면 낮게.

분류 목록:
{kinds}

메뉴명:
{items}

입력과 같은 개수를, 같은 index 로 답한다.
